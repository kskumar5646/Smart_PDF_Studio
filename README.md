# Smart PDF Studio

Modern static browser-first PDF, document and image toolkit.

## Included
- Responsive mobile/tablet/desktop interface
- 60 categorized tools
- Dedicated workspace modal for every tool
- Image Compressor in Popular Tools
- Navy primary Process/Download actions
- 10-language selector shell
- Legal pages, sitemap, robots.txt and web manifest
- GitHub Pages deployment workflow

## Privacy architecture
This project is static. It has no application backend or file-upload API. Supported processing is performed in the browser using client-side libraries.

## Important
Not every advanced format conversion can be reproduced at professional desktop fidelity using only lightweight browser libraries. The interface does not claim server-side processing where none exists.

## Deployment
GitHub Pages is deployed from the `main` branch using `.github/workflows/pages.yml`.
